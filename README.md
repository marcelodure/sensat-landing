# Landing de Sensat Studio

Página de [sensatstudio.com](https://sensatstudio.com): una sola página en HTML, CSS y un poco de JavaScript, sin dependencias.

- Se publica sola con **GitHub Pages** cada vez que se sube un cambio a `main`.
- `CNAME` indica el dominio y `.nojekyll` evita que GitHub procese los archivos.
- Las versiones de trabajo (v1 a v5) están en el Escritorio de Marcel, en la carpeta «Landing Sensat - preview 13-10-2026».
